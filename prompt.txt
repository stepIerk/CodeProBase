Ты — опытный backend-разработчик. 
Сгенерируй начальный код Telegram-бота для онлайн-курсов для детей.

Требования к проекту:

1. Стек:
- Node.js + JavaScript
- Telegram bot: Telegraf
- PostgreSQL
- dotenv
- Без serverless, бот запускается как обычный Node-процесс
- Архитектура с возможностью расширения (сайт + бот используют одну логику)

2. Структура проекта:
server/
 ├─ src/
 │   ├─ bot/            // логика Telegram-бота
 │   ├─ db/             // подключение к PostgreSQL
 │   ├─ services/       // бизнес-логика (общая для бота и сайта)
 │   └─ index.js        // entry point
 ├─ package.json
 └─ .env

3. Логика бота (MVP):
- Пользователь может оставить заявку на курс через Telegram
- Заявка включает:
  - telegram_id
  - имя родителя
  - имя ребёнка
  - выбранный курс
- После заявки бот отправляет подтверждение пользователю
- Администратор (один преподаватель) получает уведомление о новой заявке

4. ВАЖНО:
- Заявка на курс и конкретные занятия — разные сущности
- На этапе заявки время НЕ выбирается
- Время занятий назначается позже администратором

5. Архитектурные требования:
- Подключение к PostgreSQL через отдельный модуль
- Вся логика записи вынесена в service (например booking.service)
- Telegram-бот использует этот сервис, не работает с БД напрямую
- Состояние диалога пользователя можно хранить в памяти (Map) как MVP

6. База данных:
Создай SQL для таблицы bookings:
- id
- telegram_id
- parent_name
- child_name
- course
- status (pending / active / canceled)
- created_at

и придумай как хранить рассписание где время назначается админом после согласования:

booking_id
weekday
time
duration
active

7. Код:
- Покажи файлы полностью
- Без лишнего UI
- Комментарии в коде приветствуются
- Код должен запускаться после установки зависимостей и заполнения .env

8. Не добавляй:
- оплату
- сложную админку
- выбор времени пользователем
- serverless / Vercel

Результат:
Полный минимальный рабочий стартовый код Telegram-бота, готовый к дальнейшему развитию
(назначение занятий, напоминания, переносы).

Родитель может запросить отмену урока/перенос
За 2 часа должно быть напоминание об уроке
Админ должен легко выставлять время.
